# «Переплёт» — электронная библиотека

Учебный проект (задание 12): каталог книг с личной полкой, статусами чтения,
оценками, заметками, статистикой и рекомендациями. Статический сайт без сборки
и зависимостей: HTML, CSS и JavaScript.

## Как открыть

Откройте `index.html` в браузере или запустите любой статический сервер из этой папки:

```
python3 -m http.server 8000 --directory library
```

и перейдите на http://localhost:8000.

## Что есть

- **Каталог** — 32 книги восьми жанров: название, автор, жанр, год первой
  публикации, объём, обложка и аннотация.
- **Поиск** по названию и автору (без учёта регистра и «ё»), **фильтры** по жанру
  и году (поля «с/по» и быстрые периоды), **сортировка** по названию и по дате
  публикации.
- **«Показать ещё»** — по 12 книг. Фильтры, сортировка и число показанных книг
  сохраняются после перезагрузки.
- **Карточка книги** — каталожная карточка, аннотация, похожие книги и панель полки.
- **Моя полка** — статусы «Хочу прочитать / Читаю / Прочитано», оценка 1–5,
  заметки (автосохранение), вкладки по статусам, удаление с отменой.
- **Читательский формуляр** — прочитано книг и страниц, средняя оценка,
  прочитано за год, статусы и жанры прочитанного.
- **Рекомендации** — по 2–3 жанрам, которые пользователь читает чаще всего;
  книги с полки не повторяются.

Полка хранится в `localStorage` как объект «id книги → запись», поэтому книга
не может оказаться на полке дважды. Любое изменение статуса сразу
пересчитывает статистику и рекомендации. Для быстрой проверки на пустой полке
есть кнопка «Заполнить примером».

## Оформление

Фон `#FCFBF8`, бордовый `#773D4D`, графит `#222222`. Заголовки и названия —
Merriweather Bold, описания, кнопки и фильтры — Source Sans 3 (Google Fonts).
Обложки рисуются CSS в пропорции 2:3, карточки в сетке одной высоты,
на телефоне — выпадающее меню и фильтры по кнопке.

## Файлы

- `index.html` — разметка страницы
- `css/styles.css` — стили
- `js/books.js` — данные каталога
- `js/app.js` — маршруты, фильтры, полка, статистика и рекомендации
